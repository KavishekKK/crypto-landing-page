# Krypto

A modern cryptocurrency landing page built with HTML and CSS only.

## About

Krypto is a practice landing page for a fictional crypto trading plattforms.
I build it to practice layout, typography and section design using plain HTML and CSS, with no frameworks or Javascript.

## Sections

- Navbar
- Hero
- Stats
- Features Card
- How it Works (3 steps)
- CTA Banner 
- Footer

## Built with

- HTML5
- CSS3
- Google Fonts (Space Grotesk, Inter)
- Font Awesome Icons

## What I learned

- Building a full page layout with CSS Grid and Flexbox
- Alternation light and dark sections for visual rhythm
- Styling reusable components like cards, buttons and section headers

## Future Improvements
- Make the layout responsive for tablets and phones
- Add a mobile hamburger menu
- Add scroll animations
